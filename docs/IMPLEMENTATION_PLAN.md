# Townlight Notice Implementation Plan

Townlight Notice v0.2.0 preserves the deterministic foundation and aligns it to the `civiccore v1.2.0` release wheel: runtime shell, sample notice registry, Townlight Core-backed deadline tracking, deterministic statutory rule checks, notice drafting templates, accessibility and language-readiness packets, publication readiness tracking helper, channel planning helper, subscriber delivery planning, archive/handoff packets, notice and records export checklist, and public sample UI.

Later releases add statutory rule packs, CivicClerk/CivicProcure/CivicBoards handoffs, Townlight Records file links, proof queues, publication-system integrations, and production data governance.
